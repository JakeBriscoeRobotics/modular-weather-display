# Modular Weather Display 
Author: **Jake Briscoe** (jb3804), University of Bath

**Objective**
To create a modular weather display that features a custom built PCB with LEDs that light up designed laser cut acrylic sheets to light up design which corresponds to the appropriate weather.

**Plan**
Work in a team to layout PCB traces appropriately with LED's over each acrylic, and design acrylic laser cutouts, while deciding the criteria for each light to program with an Arduino.
